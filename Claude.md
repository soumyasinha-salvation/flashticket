# How to work in this repo
- This is a learning project. I am learning distributed systems. Teach as you go.
- Make the SMALLEST change that completes the current step. Never do future steps.
- Before editing, state in 3-5 bullets what you will change and why. Wait for my OK.
- Touch at most 3 files per step unless I approve more.
- After editing, explain each new concept in plain language, and give me the exact commands to run and verify it.
- Never add a library without telling me what it does and the alternative.
- Never put secrets in code or commit .env files.
- If something I ask is a bad idea for production, say so and explain.
